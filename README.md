# 게임잡 매쳐

기획 공고를 수집·분석하고, 선택한 축에 따라 정렬하고, 지원 현황까지 관리하는 Windows 스터디 도구입니다.

## 처음 사용

1. [최신 배포 다운로드](https://github.com/jihong1202gd/gamejob-matcher/releases/latest)에서 **GAMEJOB-Study-Pipeline-Setup.exe**를 받습니다. `Source code` 압축은 설치 파일이 아닙니다.
2. EXE를 실행해 **새 폴더**에 풉니다. 기존 사용 폴더를 덮어쓰지 않습니다.
3. `대시보드 열기.cmd`를 실행합니다. **기본 축으로 정렬된 공고와 담당업무를 바로 볼 수 있습니다.** AI 연결이나 포트폴리오 준비는 첫 열람에 필요하지 않습니다.
4. `지원 상태 · 마감 관리`에서 지원·면접·과제·마감 상태를 기록합니다. 종료는 `도구 종료.cmd`입니다.

기본 축은 서브컬처·전투 액션 지향의 공통 기준이며 개인 역량·서류 합격 가능성을 평가하는 순위는 아닙니다. 동봉 자료는 수집 당시의 사본입니다. 실제 모집 상태는 공식 지원 사이트에서 확인하세요.

## 관심 공고와 간결한 목록

공고에서 **☆ 관심 저장**을 누르고 목록 선택의 **관심 저장**에서 모아 보세요. **★ 저장됨**을 누르면 해제됩니다. 관심 상태는 지원·마감과 별개로 유지되며 앱 재시작과 프로필 전환 후에도 남습니다. 관심기록은 공유 프리셋에 포함하지 않습니다.

목록에서는 회사·직무·핵심 업무를 먼저 봅니다. **전체 업무·정렬 정보**를 펼치면 전체 업무와 거리·미확인 정보를 확인합니다. 정렬 수식이나 기존 판정 결과를 바꾸지 않는 화면 개선입니다.

## AI는 새 공고·새 기준을 판정할 때 연결

`AI 연결 · 파일 작업`에서 연결 하나를 선택하고 저장합니다. 로그인한 Codex/Claude는 실행 파일 자동 감지와 프로그램 기본 모델(`auto`)을 지원합니다. API는 본인의 HTTPS 주소·모델·키 환경변수 이름을 입력합니다. 지금 쓰는 AI와 요청/응답 JSON을 수동으로 주고받는 방식도 지원합니다. OpenAI는 필수가 아닙니다.

간편 연결은 선택한 단계만 켜고 다른 단계·자동 실행은 잠시 끕니다. 이전 연결 값은 보존합니다. 시험 후 고급 설정에서 다시 켤 수 있습니다. 연결 저장만으로 작업을 시작하지 않습니다. 미판정 공고가 있을 때 `준비된 공고 최대 3건 시험`으로 확인하세요. 요약·의미분석·짝 검토에도 같은 AI를 사용하는 선택지가 있고, 본인 패키지·공유 프리셋·OCR·수집·자동 실행은 펼쳐 보는 설정에 남겨 두었습니다. 새 설치의 모델 호출·수집·자동 실행은 꺼져 있습니다.

제작자의 개인 문서·지원기록·API 키·로그인 정보는 포함하지 않습니다. 사용한 설치 폴더에는 본인 자료가 생길 수 있으므로 그 폴더를 다시 배포하지 마세요. 새 버전은 새 폴더에 풀어 확인하고, 기존 폴더는 지원기록 보존을 위해 그대로 두세요. 기록 백업·이전에서 기존 지원/관심 기록과 설정을 가져올 수 있습니다.

이 저장소는 EXE와 설명서를 배포하는 곳입니다. 포트폴리오 프로젝트와 분리돼 있습니다.


## 새 버전으로 기록 이전

기존 버전을 정상 종료하고 새 폴더에 설치한 뒤 **기록 백업·이전**에서 기존 폴더 또는 개인 백업 JSON을 선택하세요. 지원/관심 기록과 설정·프리셋 슬롯을 미리보기 후 가져옵니다. 중복은 현재 기록 유지가 기본이며 적용 전 자동 백업과 후속 수정 전 되돌리기가 있습니다. 기존 폴더는 변경하지 않습니다. AI·수집·자동 실행·전송 동의는 꺼집니다. 키 값·로그인·개인 문서/프로필·판정 결과·큐는 옮기지 않습니다. 백업에는 비공개 지원 메모가 있으므로 공유하지 마세요.
