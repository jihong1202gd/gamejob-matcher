# 게임잡 매쳐

게임기획 취업 스터디용 **공고 수집·분석·매칭·정렬·지원 관리 도구**입니다.
이 저장소는 배포 파일과 사용 안내를 위한 별도 저장소입니다.

## 다운로드

[최신 배포판과 사용설명서 받기](https://github.com/jihong1202gd/gamejob-matcher/releases/latest)

**Assets의 `GAMEJOB-Study-Pipeline-Setup.exe`를 받으세요.**
자동 생성되는 `Source code (zip)`은 실행 프로그램이 아닙니다.

## 설치와 첫 실행

1. Windows PC에서 EXE를 실행하고 짧은 경로의 **새 폴더**에 압축을 풉니다. 기존 설치를 덮어쓰지 않습니다.
2. 추출한 폴더의 `대시보드 열기.cmd`를 실행합니다.
3. 공고·담당업무 열람과 지원·마감 관리는 바로 사용할 수 있습니다.
4. 종료할 때는 `도구 종료.cmd`를 실행하세요. 브라우저만 닫으면 백그라운드 작업이 남을 수 있습니다.

Python 3.12 64비트와 필수 라이브러리는 EXE에 포함됩니다. 대형 AI 모델과 계정·API 키는 포함하지 않습니다.

## 정렬을 시작하려면

**기준을 선택하는 것만으로 순위가 생성되지는 않습니다.**

- **기본 제공 축**: 서브컬처·전투 액션 지향의 축으로 관심 방향을 비교합니다. 제작자 개인 경험이나 제출문서는 제공하지 않습니다.
- **사용자 맞춤**: 본인 문서를 분해하고 근거를 연결해 매칭합니다.
- **공유 프리셋**: 받은 축 파일을 저장·선택합니다. 현재 입력과 일치하는 공개 판정 캐시는 재사용합니다.

`내 자료 · 모델 설정`에서 기준 선택 → **공고 축 판정 · 개인 매칭의 AI 실행 방법 연결** → 실행 설정 저장 → `공고 갱신 · 작업 실행` 순서입니다. 기존 판정이 없으면 첫 판정에 AI 사용량이 발생합니다. 판정 저장 뒤 거리 계산과 전체 정렬은 프로그램이 수행합니다.

Claude/Codex 로그인 CLI, 지원 API, 에이전트 파일 교환 등을 선택할 수 있습니다. 선택한 방식의 설치·로그인·모델 이용 권한은 본인이 준비해야 합니다. API 비용과 구독 한도는 별개입니다. 이미지 판독에는 이미지 입력을 지원하는 연결이 필요합니다.

## AI에게 설정 안내받기

설치 폴더의 `AI-에이전트용-설명서.md`를 에이전트에게 주고, `AI-시작요청.txt`의 문장도 함께 보내세요. Codex에서는 설치 폴더를 작업 폴더로 열고 새 채팅에서 시작합니다. API 키 값이나 로그인 파일을 채팅에 붙여 넣지 마세요.

## 갱신과 자료 관리

- 수집·모델 호출·자동 실행은 처음에 꺼져 있습니다. 필요한 실행 방법을 연결하고 소수 공고부터 시험하세요.
- 자동 처리는 PC와 도구가 켜져 있는 동안 진행합니다.
- 동봉 공고는 수집 당시 자료입니다. 실제 마감 여부는 공식 지원 사이트에서 확인하세요.
- 사용한 설치 폴더에는 본인 문서와 지원기록이 쌓입니다. 재배포는 사용한 폴더 대신 원본 EXE로 하세요.

## 시험판 범위

설치·저장·수신·계산·게시 등은 로컬 모의 응답으로 검증했습니다. 실제 공급자 인증·모델 품질·다른 PC에서의 동작은 별도 확인이 필요합니다. 추천 품질이나 서류 합격률을 보장하지 않습니다.
